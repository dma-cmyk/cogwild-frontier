## 見つかった問題

バグ（誤動作）は見つからなかった。以下はすべて UX（分かりにくさ）の指摘。

### 中: 攻撃命令で中立ユニットを指定しても何も伝えない
- 再現: 攻撃ボタン → 中立の村の住民をクリック（`combat` ステップ 106–107、Shift なし）。
- 実際: 地面に赤い円が出るだけで、上部の「攻撃: 対象をクリック…」の案内も残る。攻撃が通ったのか、拒否されたのかが分からない。
- 期待: 「中立には攻撃できません」などの通知を出すか、指定モードを抜ける。
- 証拠: `combat_106_attack_tengu.jpg`、ログ ERROR なし。

### 低: 伐採ゾーンを敷いた直後の表示が薄い
- 再現: 採集 → 伐採 → ドラッグ。
- 実際: ゾーンの境界が薄い緑の線だけで、命令が入ったかは資源が増えるまで分からなかった。
- 証拠: `onboard_018_dragged_logging.jpg`

### 低: 存在しない小隊の番号キー・Tab に反応がない
- 再現: 小隊が1つの状態で `2` や `Tab`。
- 実際: 音も表示も出ず、キーが効いていないのか小隊が無いのかが判別できない。
- 証拠: `combat_028_key2.jpg`

### 低: 能力が使えないときの理由が出ない
- 実際: 「使用できない能力です」とだけ出て、クールダウン中なのか対象が不正なのかが分からない（`watch_031_31_shoot_orc.jpg` の左上）。

### 低: 「採集」という名前のボタンが2段にある
- 右下の命令バーの「採集」と、その上に開くサブメニューの「採集（食料）」が同じ名前。

### 低: 遠くの集落が敵か中立か、発見するまで分からない
- 柵や櫓が見えて敵の野営地と思って近づいたら、中立の村だった。
